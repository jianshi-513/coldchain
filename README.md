# ColdChain Simulator · 冷链物流模拟系统

一个可运行的本地桌面冷链物流数字孪生/运营仿真原型。系统使用统一模拟时间推进仓储、预冷、装卸、运输、温度、货物品质、卫生污染、设备异常、成本和追溯流程。

> 本项目用于教学、流程演练和调度方案比较。温度、品质与污染结果是简化仿真模型，不构成食品安全结论，也不表示自动符合任何国家标准。具体业务阈值应由企业 SOP 与专业人员配置。

## 快速开始

需要 Python 3.12 或更高版本。

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

也可在安装依赖后双击或运行：

```powershell
.\run.ps1
```

运行测试：

```powershell
python -m pytest
```

数据库会在第一次启动时创建于 `data/coldchain.db`；订单 JSON 报告和事件 CSV 位于 `reports/`。SQLite 使用 WAL，温度按配置间隔缓存、批量写入，不会每个 tick 对所有对象提交。

## 操作验收场景

首次启动已创建武夷山、福州、厦门和南昌仓，以及 A01~A04 车辆、F01~F04 叉车、8 个示例批次和 8 张配送订单。酸奶验收订单为 `CL202609010001`，其余订单覆盖冰淇淋、水果、冷冻猪肉、鲜奶、叶菜和速冻水饺。

1. 进入“订单与调度”，选择 A02/A02-C 并分配。
2. 点击“开始预冷”，再点击右上角“开始”；可用 ×50 或 ×100 观察车厢从 31℃ 逐步降温。
3. 预冷完成后选择 F03（乳制品专用、清洁）并“开始履约”。
4. 系统自动经历拣货、暂存、月台、开门装车、封签和运输。
5. 可在“车辆”制造 25 分钟拥堵、切换车门或制造制冷故障。
6. 到达后回到订单页点击“到达后卸货”，完成交接和签收。
7. 在“报表”生成订单 JSON 报告；“追溯与召回”可定位或召回批次。

卫生反例：F01 初始状态为“泄漏猪肉汁、待清洁消毒”。正常选择时系统会阻止它搬运酸奶；勾选“强制执行”后可以继续，但货物污染风险、严重事件和审计日志都会增加。卫生页要求先清洁、再消毒。

冰淇淋/停电场景：可以新建逻辑订单（当前 GUI 第一版使用预置订单），或直接在车辆页对 A01 制造制冷故障；仓库页可以切断 WYS 供电。空气温度会先变化，货物核心温度因热惯性缓慢响应，不会瞬间报废。

## 已实现

- PySide6 深色桌面界面，12 个业务页面，QTimer 非阻塞驱动。
- 统一 `simulation_time`，暂停及 ×1/2/5/10/20/50/100 倍速。
- 固定随机种子；一分钟内部子步保证高倍速下状态转换稳定。
- 仓库、多库区、月台、车辆、多温区车厢、叉车、批次货物和订单实体。
- 车辆容量同时校验重量、体积和托盘位；温区不匹配可拦截或强制。
- 一阶热交换：环境/库区/车厢空气与货物表面/核心温度彼此分离。
- 制冷回差、压缩机负载、能耗、自动除霜、开门热交换、车辆预冷。
- 冷库断电与恢复、制冷故障与维修、拥堵、车门、传感器偏差/卡死/离线干预。
- 酸奶订单的拣货→暂存→月台→装车→封签→运输→卸货→签收状态机。
- 月台资源占用；无空闲月台时货物继续等待并承受暂存区温度。
- FEFO 批次选择服务、效期字段、库存状态和隔离状态。
- 累计超温分钟、度分钟、品质衰减、污染风险和包装完整性。
- 叉车卫生兼容、污染传播、清洁/消毒分离、强制作业审计。
- 批次追溯与召回；召回货物进入隔离而非被删除。
- KPI、温度曲线、事件中心、SQLite 审计/卫生/维护/交接/召回表。
- JSON 订单报告和 CSV 事件导出。
- 15 类可编辑默认货物参数及独立企业卫生 SOP 配置。

## 简化模型

- 热模型采用集总参数的一阶传热，不是 CFD 或制冷工程设计工具。
- 环境温度采用昼夜余弦曲线；路线位置用剩余公里数表示，没有 GIS 地图。
- 品质以可配置的时间—温度暴露系数估算，不是微生物预测模型。
- 污染风险为规则化教学分值；具体“生肉→乳品”规则明确作为企业 SOP 示例。
- 月台、叉车作业使用阶段时长和队列资源模型，没有人员个体与三维空间仿真。
- 成本目前覆盖能源、阶段人工、品质损失和逾期罚金。

## 架构

```text
coldchain_simulator/
├── main.py                    # 应用入口
├── config/                    # 模拟、货物、卫生参数
├── coldchain/
│   ├── entities.py            # 领域实体与枚举化状态
│   ├── engine.py              # 统一时钟及运营状态机
│   ├── physics.py             # 热交换、制冷、品质模型
│   ├── hygiene.py             # 卫生兼容与污染传播
│   ├── database.py            # SQLite、缓存采样、导出
│   ├── demo.py                # 可运行演示数据
│   └── ui/                    # 业务界面、自绘温度图、主题
└── tests/                     # 时钟、温控、状态机、卫生等测试
```

主要参数位于 `config/defaults.json`，包括 tick、采样间隔、传热系数、开门倍率、制冷回差、除霜、品质系数、作业时长和成本。修改后重启程序生效。
